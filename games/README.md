# Браузерные игры: Orbit Hop · Merge Drop · Neon Dodge

Три оригинальные HTML5-игры. Каждая — один файл `index.html` без зависимостей,
работает на телефоне (касание) и компьютере (мышь/клавиатура). Звук и рекорды встроены.

Сборка: `./build.sh` → `dist/<игра>.zip` (готовые архивы для загрузки на площадки).

## Как зарабатывать

Площадки сами приводят игроков, показывают рекламу и платят вам долю.

1. **CrazyGames** — developer.crazygames.com → Sign up → Submit game → загрузите zip.
   Рекламный SDK CrazyGames подключается в игре автоматически, когда она открыта на их сайте
   (реклама между раундами, раз в 2 игры). Перед отправкой сверьтесь с их актуальной документацией SDK.
2. **GameDistribution** (gamedistribution.com/developers) — раздаёт игры сотням сайтов;
   требует свой SDK — подключается по их инструкции при загрузке.
3. **itch.io** — загрузите zip как HTML-игру, можно включить «pay what you want».

Выплаты обычно раз в месяц от минимального порога; нужен PayPal или банковский счёт.
