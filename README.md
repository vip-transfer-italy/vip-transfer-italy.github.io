## 1. Деплой на Arkway.me

1. Зайди на [arkway.me](https://arkway.me) і зареєструйся / увійди.
2. Створи новий сайт (New Site / Upload).
3. Завантаж **вміст** папки `vip-transfer` (файли `index.html`, `style.css`,
   `script.js` і папку `images` разом з фото). `index.html` має бути в корені.
4. Готово — сайт одразу доступний за виданим посиланням.

### Запасний варіант — Netlify (безкоштовно)

1. Зайди на [app.netlify.com/drop](https://app.netlify.com/drop).
2. Перетягни всю папку `vip-transfer` у вікно браузера.
3. Через ~10 секунд отримаєш посилання виду `https://random-name.netlify.app`.
   Домен можна змінити в Site settings → Domain management.

### Або Vercel

1. [vercel.com](https://vercel.com) → Add New → Project → Upload
   (або через GitHub-репозиторій).
2. Framework preset: **Other**, нічого не збирається — просто статичні файли.

### Або GitHub Pages

1. Створи репозиторій, залий у нього файли (index.html у корені).
2. Settings → Pages → Source: `main` branch → Save.
3. Сайт буде на `https://<нік>.github.io/<репозиторій>/`.

## 2. Сповіщення про заявки в Telegram (варіант A — основний)

Заявки з форми приходять тобі в Telegram через твого бота.

### Крок 1. Створи бота

1. Відкрий Telegram, знайди **@BotFather**.
2. Надішли команду `/newbot`.
3. Вкажи ім'я бота (напр. `VIP Transfer Bookings`) і username
   (має закінчуватись на `bot`, напр. `viptransfer_bookings_bot`).
4. BotFather пришле **BOT_TOKEN** — рядок виду
   `7123456789:AAHf3k...xyz`. Скопіюй його.

### Крок 2. Дізнайся свій CHAT_ID

1. Знайди свого нового бота в Telegram і надішли йому будь-яке
   повідомлення (напр. «привіт») — це обов'язково, інакше бот не
   зможе тобі писати.
2. Відкрий у браузері (підстав свій токен):
   ```
   https://api.telegram.org/bot<ТВІЙ_BOT_TOKEN>/getUpdates
   ```
3. У відповіді знайди `"chat":{"id":123456789,...}` —
   це число і є твій **CHAT_ID**.

### Крок 3. Встав значення в script.js

Відкрий `script.js`, вгорі файлу заміни:

```js
const TELEGRAM_BOT_TOKEN = '7123456789:AAHf3k...xyz';  // твій токен
const TELEGRAM_CHAT_IDS = [
  '123456789',   // твій chat id
  '987654321'    // (необов'язково) ще один отримувач — заявка прийде обом
];
```

Готово — кожна заявка з форми прилітатиме тобі в Telegram.

> ⚠️ Нюанс: токен бота лежить у відкритому JS-коді сайту, тобто його
> технічно може побачити будь-хто. Для бота, який вміє лише писати тобі
> повідомлення, це прийнятний компроміс для простого лендінга. Якщо
> хочеш повністю сховати токен — використовуй варіант B (FormSubmit)
> або серверну функцію (Netlify Functions).

## 3. Альтернатива: заявки на email через FormSubmit.co (варіант B)

Якщо Telegram-бот незручний — без реєстрації і ключів:

1. У `script.js` вгорі постав:
   ```js
   const USE_FORMSUBMIT = true;
   const FORMSUBMIT_EMAIL = 'твоя_пошта@gmail.com';
   ```
2. Відправ першу тестову заявку з сайту — FormSubmit пришле
   лист-підтвердження на цю пошту. Натисни в ньому кнопку підтвердження.
3. Після цього всі заявки приходитимуть листами на твою пошту.

(Є ще EmailJS — emailjs.com — але він потребує реєстрації та ключів,
тому FormSubmit простіший.)
