# Мой кошелёк

Некастодиальный веб-кошелёк: **BTC**, **ETH**, **USDT (ERC-20)**, **TRX**, **USDT (TRC-20)**.
Ключи создаются и хранятся только в браузере. Серверов и регистрации нет.

## Как устроено
- Секретная фраза BIP39 из 12 слов. Совместима с Trust Wallet, MetaMask и TronLink: те же пути вывода
  (`m/84'/0'/0'/0/0` для BTC, `m/44'/60'/0'/0/0` для ETH, `m/44'/195'/0'/0/0` для TRON).
- Фраза хранится в `localStorage`, зашифрованная AES-256-GCM. Ключ шифрования получается из пароля
  через PBKDF2-SHA256 (600 000 итераций). Через 5 минут бездействия кошелёк сам блокируется.
- Криптография: аудированные библиотеки `@noble/*` и `@scure/*`. Они собраны в `wallet.js`
  с зафиксированными версиями, без CDN. Строгий CSP запрещает сторонние скрипты.
- Транзакции подписываются локально. Наружу уходит только готовая подписанная транзакция.
  Для этого используются публичные API: publicnode (Ethereum), TronGrid (TRON) и mempool.space (Bitcoin).
  Узлы можно поменять в настройках.
- Транзакцию TRON собирает TronGrid. Кошелёк сначала проверяет `txID = sha256(raw_data)`,
  отправителя, получателя и сумму и только потом подписывает.

## Запуск
Страницу нужно открыть по **https** или с `localhost`: браузер не даёт шифровать на незащищённых страницах.
```
npx serve .            # или python3 -m http.server, затем http://localhost:3000
```

## Разработка
```
npm install
npm test               # тесты ядра: эталонные адреса, подпись ETH сверяется с ethers, TRON, BTC, шифрование
npm run build          # собирает src/ → wallet.js
```

## Ограничения
- Один адрес на каждую сеть. Сдача BTC возвращается на тот же адрес.
- Чтобы отправить USDT, нужна монета сети на комиссию: ETH для ERC-20 и примерно 15–30 TRX для TRC-20.
- Отправка проверена тестами и на моках, но не на реальных деньгах. **Сначала переведите небольшую сумму.**
